# python-test-vscode

Simple Python script to close the daily cash register.

## What it does

Asks for the cash, outflow, previous balance, credit and debit amounts, and shows the totals:

- cash (cash total + outflow − previous balance)
- credit and debit
- balance (cash total − previous balance)
- grand total (cash + credit + debit)

## How to run

Nothing to install besides Python:

```bash
python teste1caixa.py
```
